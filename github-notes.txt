After creating a file on GitHub, you commit. Commit, in this context, means saving changes.

How to clone your remote GitHub repo on your computer (local GitHub repo):
cd to your desktop, then go back to GitHub and click on Code, then HTTPS, and copy the link and go back to gitbash or Terminal where you installed git and type: git clone [the link you copied) and click Enter. After cloning, I tried to check git status, but it didn't work because I didn't cd into the folder/directory; after cd-ing into the folder, it worked, and I was able to check the git status. Exercise I did: git clone https://github.com/ndugu1/Cloud-Devops-projects.git

To update files or changes made on the local machine from GitHub, the command to use is: git pull. This will update the newly created files on your local machine.
If you check git status on the local machine to know if the file has been modified, only the files that are committed will show as modified; the ones that have not been committed will show as untracked.
