After creating a file on GitHub, you commit. Commit in this context means saving changes.

How to clone your remote GitHub repo on your computer (local github repo):
cd to your desktop, then go back to GitHub and click on code, then HTTPS, and copy the link and go back to gitbash or terminal where you installed git and type: git clone link (the link you copied) and click enter. To update files or changes made on the local machine from githup, command to use: git pull. This will update the newly created files on your local machine.
